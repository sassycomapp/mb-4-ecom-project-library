# Mybizz Shop (mb-4-ecom) — Project Library

The documentation repository of Mybizz Shop, the e-commerce application of Mybizz. The code is built by PDLF into the `mb-4-ecom` app repositories.

## Context documents

| Document | What the document holds |
|---|---|
| `docs-local/mb-4-ecom-concept.md` | What Mybizz Shop is, who Mybizz Shop serves, the hard rules, the price (£119 a month, £1,190 a year) and the market position |
| `docs-local/mb-4-ecom-architecture-report.md` | The architecture decisions and facts that govern mb-4-ecom |
| `docs-local/mb-4-ecom-commerce-feature-list.md` | Every feature of the shop part, F-S01 to F-S14 |
| `docs-local/mb-4-ecom-commerce-schema.md` | Every table and column of the shop part |
| `docs-local/mb-4-ecom-commerce-lifecycles.md` | Every state and transition of carts, orders, payments, shipments, returns, discounts, credit accounts, disputes and the tax method |

## Folders

| Folder | What the folder holds |
|---|---|
| `docs-local/` | The context documents above |
| `docs/agents/` | Agent working notes |
| `adr/` | Architecture decision records of mb-4-ecom |
| `pre-project/` | Pre-project documents |
| `ui/` | User interface material |
| `pdlf-outputs/` | One folder per PDLF step, for the reports each step produces |
| `pdlf-temp/` | Temporary PDLF working files |
| `wip/` | Work in progress; git-ignored, never committed |

## Status

The shop part and the concept of Mybizz Shop are fully scoped. Mybizz Shop enters PDLF once Mybizz CS is finished and the common part of Mybizz CS is in the project template.
